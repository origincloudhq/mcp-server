# Origin Cloud MCP server

The hosted [MCP](https://modelcontextprotocol.io) server of
[Origin Cloud](https://origincloud.eu): the tools of
[origincloudhq/mcp](https://github.com/origincloudhq/mcp), served over MCP's
Streamable HTTP transport to any MCP client that connects by URL.
